## ⚡ What is STRYV?

STRYV is being built to give you a more focused way to understand, manage, and improve your PC experience.

Instead of scattering useful tools across different applications, STRYV aims to bring system insights, diagnostics, gaming workflows, and intelligent assistance together under one interface.

The project is actively evolving. Some functionality is already implemented, while larger systems remain in development.

## 🖥️ Features

### Available in the current application

- **System Monitoring** — CPU and memory usage, uptime, disk information, and running processes.
- **GPU Telemetry** — NVIDIA GPU information on supported systems.
- **Network Diagnostics** — Connection checks, latency tests, DNS diagnostics, and network throughput information.
- **System Tools** — System information and selected cleanup and optimization utilities.
- **Activity Logs** — Review recorded application actions and diagnostic information.
- **Settings & Controls** — Persistent settings, keyboard shortcuts, and a command palette.
- **Startup Animation** — A rocket-launch sequence introducing the application.

*Feature availability can depend on hardware, permissions, and Windows configuration. The application and its packaging are still being verified.*

## 🚀 The Vision

STRYV is designed to grow beyond its current feature set.

### ATLAS — Gaming

A planned gaming hub focused on game discovery, library organization, launching, profiles, session history, and future gaming integrations.

### SYN — Intelligence

A planned AI and knowledge layer intended to connect assistance, searchable knowledge, local notes, and useful workflows.

### WorkGuard — Protection

A planned system focused on preserving work, checkpoints, and recovery workflows.

These systems represent the broader direction of STRYV. They are not being presented as released features unless and until they are implemented and verified.

## 🔒 Privacy & Safety

STRYV can access local system information, and some tools may perform system-level operations.

Review the behavior of an operation before approving it. Hardware support, permissions, and system configuration may affect results.

When reporting issues, remove personal information, credentials, API keys, and other sensitive data from logs and screenshots.

## 🐛 Reporting Issues

When reporting a problem, include:

- The STRYV version, if available.
- Your Windows version.
- What you expected to happen and what actually happened.
- Steps to reproduce the issue.
- Relevant logs with sensitive information removed.

Please avoid posting passwords, API keys, account tokens, or other secrets.
