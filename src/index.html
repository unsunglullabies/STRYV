Reading launcher files
STRYV reads only what the launcher wrote. Launching a Steam game asks Steam to start it through Steam's own link handler; ATLAS never runs a Steam title's files directly. Games you add yourself are launched directly, because there is no launcher to ask. Removing an entry only removes it from ATLAS. It never uninstalls the game or deletes any file.

Help & About

About

STRYV: push your performance. A Windows PC performance and diagnostics utility. Built with Tauri and the sysinfo library. License: not yet specified.

Updates

STRYV checks for signed updates and can install them from inside the app. Every download is verified against the public key built into this version; an update that fails verification is discarded and never run. If no signed release has been published yet, Check now simply reports that you are up to date.

Troubleshooting

  • A reading says Unavailable. That measurement isn't supported yet or the system didn't provide it. STRYV never fills in guessed values.
  • Connection tests fail. A firewall or VPN may block outbound connections on port 443. Check the Technical log in Activity.
  • Something looks wrong. Open Activity, copy the details, and include them in a bug report.
  • Start fresh. Settings, then Data, then Reset settings or Delete all STRYV data.
