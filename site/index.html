STRYV

Push your performance.

A Windows desktop system monitor that shows you what your machine is actually doing — CPU, memory, GPU, storage, network, temperatures and processes — and keeps the fixes and your games in the same window.

What it is

One native Windows window instead of five separate utilities, and one consistent rule about change: measure freely, act deliberately.

Platform Windows 10 and Windows 11, 64-bit (x64).
Built with Tauri 2 and Rust. The interface is hand-written HTML, CSS and JavaScript with no framework, no bundler and no runtime dependencies — the same constraint the desktop app holds itself to.
Measurements Read live from this PC. Nothing is sampled, averaged or filled in to make a graph look complete.
System changes Fixed, reviewed actions with a confirmation step and an entry in the activity log. Switching the power plan and toggling startup apps are reversible; deleting temp files is not, and is labelled that way before you confirm it.
Your data No account, no analytics, no telemetry leaving the machine. Settings and the game library are files in your local app data directory.
Source Public on GitHub at unsunglullabies/STRYV.

Inside the app

Eight things STRYV does today, in the order they matter.

Dashboard

CPU and memory lead, with uptime, storage, temperature and network supporting them, plus a system-health summary that grades memory pressure, sustained CPU, free space and uptime and labels its own confidence.

Performance

Two-minute CPU and memory graphs sampled on a timer you choose, temperature sensors where Windows exposes them, and the top processes by CPU share — with a note that a busy process is not automatically the bottleneck.

Network

Live throughput measured from actual traffic, the adapter list, the negotiated link speed to your router, and one-click TCP latency and DNS lookup tests. It does not pretend to be a speed test.

GPU telemetry

Load, memory, temperature and clocks on NVIDIA cards. AMD and Intel readings are not supported yet, and the app says so instead of showing zeros.

Optimizations

Switch the Windows power plan, clear temporary files older than a day, and control your startup apps. Each item states its tradeoffs, whether it needs Administrator, and whether it is reversible — then waits for your confirmation.

ATLAS library

Every installed Steam game this PC reports, read from the manifests the launcher has already written. Launch through Steam's own handler and track how long you actually played.

Activity & settings

Every action STRYV takes is logged with its outcome, plus a separate technical log. Persistent settings, a Ctrl+K command palette, data export and reset.

Signed updates

An in-app updater fetches the published release, verifies the download against the signing key built into the app, and discards anything that fails. Check on demand, or let it look quietly in the background.

ATLAS

The game library. STRYV finds what you already have by reading the files each launcher has already written — no account, no store, no re-scanning your disk for executables.

What ATLAS does not do

It never runs a Steam title itself

Launching asks Steam to start the game through Steam's own link handler. ATLAS reads the library manifests on disk and never writes to them. Epic, Riot, Battle.net and GOG are not read yet, and only Steam games can be launched from the library.

Aery

The knowledge system. Notes you own, written in plain Markdown on your own disk, with links between them so you can see how ideas actually relate.

What it is meant to be

Not a notes page bolted onto a system monitor. A workspace that sits beside the rest of STRYV: write in Markdown, link notes to each other with [[double brackets]], tag them, search across everything, and watch the relationships form.

Every note is a readable .md file in a folder you choose. If STRYV disappeared tomorrow your notes would still open in any editor, because they were never trapped inside it.

Where it actually is

Aery is not shipped. Nothing on this page is available to download yet, and no part of the current release contains it.

The design work is settled: the vault, the editor, backlinks, tags and search. It is being built behind the same rule everything else here follows - no feature that says it knows something it does not.

The larger direction

STRYV is one window with three separate systems in it. They share a design language and a refusal to guess, but they are not the same thing.

Available now

Monitoring

Live CPU, memory, GPU, storage and network readings, plus diagnostics and the optimisation tools. This is what the release gives you today.

Available now

ATLAS

Your games, found from files launchers already wrote. Launch them, edit what ATLAS got wrong, and see how long you actually played.

In development

Aery

A local Markdown vault with connected notes, tags and search. Not in any release yet.

Planned

WorkGuard

Protection and recovery workflows for the things you would rather not lose. Early thinking, nothing built.
