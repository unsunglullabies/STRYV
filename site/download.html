Requirements

Operating system Windows 10 or Windows 11, 64-bit. There is no 32-bit build and no macOS or Linux build.
Display runtime STRYV runs on the Microsoft Edge WebView2 runtime, which is already present on current Windows installs. You do not need to install anything else.
Administrator rights Not needed to install, measure or browse. Only switching the Windows power plan requires it, because Windows requires it. Start STRYV with Run as administrator for that one action.
Disk space The installer is roughly 5 MB; allow a little under 100 MB once installed.
Steam, for ATLAS Optional. ATLAS reads Steam library manifests from disk and adds nothing to the Steam account. Without Steam installed, the rest of the app works normally.

Install

  1. Download the installer from either link above, or from releases/latest on GitHub. That is the only place STRYV is published.
  2. Check the release page. GitHub publishes a SHA-256 digest beside every asset. If you want to confirm you downloaded what was published, compare it against the digest shown there.
  3. Run the installer. Accept the prompt, and if SmartScreen blocks it, choose More info then Run anyway. The explanation is below and this is expected.
  4. Launch STRYV. It starts on the Dashboard and begins sampling immediately. No sign-in, no configuration, no prompts to opt into anything.
  5. Let updates come to you. From 0.1.0 onward the app can update itself. Settings → Updates → Check now, or leave it in the background and it will tell you when something newer exists.

The in-app updater

Once STRYV is installed you never need this page again for a normal upgrade.

How it works

Every download is verified before it is run

STRYV fetches the published release feed from the project's GitHub Releases, downloads the installer, and checks its signature against the signing key built into the app. A download that fails verification is discarded and never launched. It checks quietly in the background and tells you when a newer version is available; Check now makes it look immediately.

One manual step

0.1.0 and earlier cannot update themselves

An app with no updater cannot deliver its own first version. If you are installing from an older build, install the current release from this page once. Every version after that arrives through the signed updater.

Why Windows warns you

Being straight about this, because a warning screen on a download you just trusted is a bad way to start.

Expected on first run

The installer binaries are not signed. The updates are.

STRYV's installable executables are not code-signed as a whole, so Windows SmartScreen can present “Windows protected your PC” and mark the publisher as unknown. That is the absence of a paid certificate, not a compromised build. If you hit it: choose More info, then Run anyway.

  • Updates are different. Packages delivered by the in-app updater are signed, and STRYV verifies that signature against the key built into the app before running anything. A failed verification is discarded.
  • You can check what you downloaded. Every asset on the release page carries a SHA-256 digest published by GitHub. Compare it and there is nothing to trust but arithmetic.
  • Everything is open. The source is public at unsunglullabies/STRYV. Releases are built and signed by GitHub Actions from tagged commits on main.
  • Prefer not to run unsigned binaries? That is a reasonable position and nothing here argues against it. The source is there to be read.
